## Цель урока

---

## Теория

### 1. Добавление данных (INSERT)
`INSERT` (Вставить) — оператор добавления новых строк в таблицу.
Синтаксис: `INSERT INTO table_name (column1, column2) VALUES (value1, value2);`

*Пример:* 
~~~sql
INSERT INTO products (name, category, price, stock) 
VALUES ('Планшет', 'Электроника', 30000.00, 15);
~~~

### 2. Обновление данных (UPDATE)
`UPDATE` (Обновить) — оператор изменения существующих записей.
Синтаксис: `UPDATE table_name SET column1 = value1 WHERE condition;`

*Пример (обновить цену ноутбука):*
~~~sql
UPDATE products SET price = 70000.00 WHERE name = 'Ноутбук';
~~~

**Важно:** без `WHERE` обновятся **все** строки в таблице.

### 3. Удаление данных (DELETE)
`DELETE` (Удалить) — оператор удаления строк.
Синтаксис: `DELETE FROM table_name WHERE condition;`

*Пример (удалить товары, которых нет в наличии):*
~~~sql
DELETE FROM products WHERE stock = 0;
~~~

**Важно:** без `WHERE` удалятся **все** строки. Восстановить их без резервной копии будет невозможно.
