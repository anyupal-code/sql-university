# Практическое задание к Уроку 2

## Цель работы
Научиться извлекать, фильтровать и сортировать данные с помощью операторов SELECT, WHERE и ORDER BY.

## Что нужно сделать

### Шаг 1. Подготовка тестовой таблицы
Откройте DBeaver, подключитесь к базе `mydb` и выполните скрипт для создания таблицы `products` и заполнения её данными:

~~~sql
CREATE TABLE products (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    category VARCHAR(50),
    price DECIMAL(10, 2),
    stock INT
);

INSERT INTO products (name, category, price, stock) VALUES 
('Ноутбук', 'Электроника', 75000.00, 10),
('Смартфон', 'Электроника', 50000.00, 25),
('Книга "SQL"', 'Книги', 1500.00, 50),
('Наушники', 'Электроника', 3000.00, 0),
('Кофеварка', 'Бытовая техника', 8000.00, 5);
~~~

### Шаг 2. Выполнение запросов
Напишите и выполните следующие SQL-запросы (записывайте их в отдельный файл или блокнот):

1. Выведите **все** данные из таблицы `products`.
2. Выведите только названия (`name`) и цены (`price`) всех товаров.
3. Выведите все товары из категории **'Электроника'**.
4. Выведите товары, цена которых **больше 10 000**.
5. Выведите товары, которых **нет в наличии** (stock = 0).
6. Выведите все товары, отсортированные по цене **от дешевых к дорогим**.
7. Выведите названия товаров, начинающихся на букву **'Н'** (используйте `LIKE`).
8. Выведите **три самых дорогих** товара.
