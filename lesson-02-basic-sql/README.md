## Теория

### 1. Выборка данных (SELECT)
`SELECT` (Выбрать) — оператор получения данных. 
Синтаксис: `SELECT column1, column2 FROM table_name;`
* `*` — все колонки.
* `FROM table_name` — источник данных.

*Пример:* `SELECT * FROM users;` (выбрать все данные из таблицы users).

### 2. Фильтрация (WHERE)
`WHERE` (Где) — оператор фильтрации строк по условию.
**Операторы сравнения:** `=`, `>`, `<`, `>=`, `<=`, `!=` (или `<>`).
**Специальные операторы:**
* `LIKE` (Похоже) — поиск по шаблону (`LIKE 'A%'` — начинается на 'A').
* `IN` (В) — проверка на вхождение в список (`IN (1, 2, 3)`).
* `BETWEEN` (Между) — проверка на диапазон (`BETWEEN 10 AND 20`).

*Пример:* `SELECT * FROM users WHERE age > 25;`

### 3. Сортировка (ORDER BY)
`ORDER BY` (Упорядочить по) — сортировка результата.
* `ASC` (Ascending) — по возрастанию (по умолчанию).
* `DESC` (Descending) — по убыванию.

*Пример:* `SELECT * FROM users ORDER BY age DESC;` (от большего к меньшему).

### 4. Ограничение (LIMIT)
`LIMIT` (Лимит) — ограничение количества возвращаемых строк.
*Пример:* `SELECT * FROM users LIMIT 5;` (только первые 5).
