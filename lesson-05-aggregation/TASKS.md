# Практическое задание к Уроку 5

## Цель работы
Научиться вычислять агрегатные показатели и группировать данные с помощью GROUP BY и HAVING.

## Что нужно сделать

### Шаг 1. Подготовка данных
Убедитесь, что у вас есть таблицы `customers` и `orders` (из Урока 4). Добавим еще пару заказов для большей вариативности:

~~~sql
-- Добавим заказы для Петра (id = 3) и еще один для Марии (id = 2)
INSERT INTO orders (customer_id, product, amount) VALUES 
(3, 'Стол', 15000.00),
(2, 'Наушники', 4000.00),
(1, 'Монитор', 20000.00);
~~~

### Шаг 2. Выполнение запросов

1. **Общая сумма:** Выведите общую сумму всех заказов (без группировки).
2. **Количество заказов:** Выведите общее количество заказов в таблице.
3. **Средний чек:** Выведите среднюю сумму заказа.
4. **Группировка по клиентам:** Выведите `customer_id` и общую сумму заказов для каждого клиента (используйте `GROUP BY`).
5. **Соединение и группировка:** Выведите имя клиента (из `customers`) и общую сумму его заказов. 
   *Подсказка:* используйте `JOIN` и `GROUP BY`.
6. **Фильтрация групп (HAVING):** Выведите имена клиентов, у которых общая сумма заказов превышает 50000.

---

## Ожидаемый результат
Вы научились считать статистику по всей таблице и по отдельным группам. Вы понимаете, зачем нужен `GROUP BY` и чем `HAVING` отличается от `WHERE`.
