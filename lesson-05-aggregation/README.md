# Урок 5. Агрегация и группировка (GROUP BY)

## Цель урока

## Теория

### 1. Агрегатные функции
Агрегатные функции (Aggregate Functions) выполняют вычисления над набором строк и возвращают одно значение.
* `COUNT()` — количество строк.
* `SUM()` — сумма значений.
* `AVG()` — среднее значение.
* `MIN()` / `MAX()` — минимальное / максимальное значение.

*Пример:* Найти общую сумму всех заказов.
~~~sql
SELECT SUM(amount) FROM orders;
~~~

### 2. Группировка (GROUP BY)
`GROUP BY` (Сгруппировать по) — разбивает строки на группы по одному или нескольким столбцам. Затем агрегатные функции применяются к каждой группе отдельно.

**Важно:** В `SELECT` можно выводить только те колонки, которые указаны в `GROUP BY`, и агрегатные функции.

*Пример:* Найти сумму заказов для каждого клиента.
~~~sql
SELECT customer_id, SUM(amount) 
FROM orders 
GROUP BY customer_id;
~~~

### 3. Фильтрация групп (HAVING)
`HAVING` (Имея) — аналог `WHERE`, но применяется к результатам группировки (к агрегатам). `WHERE` фильтрует строки до группировки, а `HAVING` — после.

*Пример:* Найти клиентов, чья общая сумма заказов больше 50000.
~~~sql
SELECT customer_id, SUM(amount) as total
FROM orders 
GROUP BY customer_id
HAVING SUM(amount) > 50000;
~~~

### 4. Применение в разработке
Агрегация используется повсеместно:
* Аналитика продаж (выручка по дням, по менеджерам).
* Подсчет статистики (количество регистраций за месяц).
* Формирование отчетов.
