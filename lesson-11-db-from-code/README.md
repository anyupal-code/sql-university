## Цель урока

* База данных `mydb`.
* **Python 3** (с библиотекой `psycopg2`) **или** **Java** (с JDBC-драйвером).
* Текстовый редактор или IDE.

---

## Теория

### 1. Зачем подключаться из кода?
SQL-клиенты (DBeaver, psql) хороши для ручной работы, но приложения должны взаимодействовать с базой данных программно: получать данные для отображения, сохранять новые записи, обновлять статусы.

### 2. Библиотеки для подключения
* **Python:** `psycopg2` (или `psycopg2-binary`).
* **Java:** JDBC (драйвер PostgreSQL).
* **C++:** `libpqxx` или `pqxx`.
* **Другие языки:** почти для каждого есть свой драйвер.

### 3. Основные шаги подключения (на примере Python)
1. **Установить библиотеку:** `pip install psycopg2-binary`.
2. **Установить соединение:** передать хост, порт, базу, пользователя и пароль.
3. **Создать курсор:** объект для выполнения запросов.
4. **Выполнить запрос:** `cursor.execute("SELECT ...")`.
5. **Получить результаты:** `cursor.fetchall()`.
6. **Закрыть соединение:** `connection.close()`.

*Пример (Python):*
~~~python
import psycopg2

conn = psycopg2.connect(
    host="localhost",
    database="mydb",
    user="myuser",
    password="mypassword"
)
cur = conn.cursor()
cur.execute("SELECT name, email FROM customers;")
rows = cur.fetchall()
for row in rows:
    print(row)
cur.close()
conn.close()
~~~

### 4. SQL-инъекции и защита от них
**SQL-инъекция** — это атака, при которой злоумышленник вставляет SQL-код через пользовательский ввод. 
*Опасно:*
~~~python
# НИКОГДА ТАК НЕ ДЕЛАЙТЕ
cur.execute(f"SELECT * FROM users WHERE email = '{email_input}'")
~~~
*Безопасно (параметризованные запросы):*
~~~python
cur.execute("SELECT * FROM users WHERE email = %s", (email_input,))
~~~
Параметризованные запросы гарантируют, что ввод будет обработан как данные, а не как SQL-код.
