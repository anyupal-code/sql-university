## Теория

### 1. Что такое транзакция?
**Транзакция (Transaction)** — это последовательность операций с базой данных, которая выполняется как единое целое. Либо все операции выполняются успешно, либо ни одна из них не применяется.

*Пример из жизни:* Перевод денег с одного счета на другой. Нужно списать сумму с одного счета и добавить на другой. Если после списания произойдет сбой, деньги исчезнут. Транзакция гарантирует, что либо обе операции пройдут, либо ни одна.

### 2. Свойства ACID
Транзакции обладают четырьмя ключевыми свойствами (ACID):
* **A (Atomicity — Атомарность):** Все операции в транзакции выполняются как единое целое. «Все или ничего».
* **C (Consistency — Согласованность):** Транзакция переводит базу данных из одного корректного состояния в другое. Данные не противоречат правилам (например, нельзя уйти в минус).
* **I (Isolation — Изолированность):** Транзакции, выполняемые одновременно, не влияют друг на друга.
* **D (Durability — Долговечность):** Если транзакция завершена успешно (COMMIT), изменения сохранятся даже при сбое питания.

### 3. Управление транзакциями
В SQL транзакции управляются командами:
* `BEGIN` (или `START TRANSACTION`) — начало транзакции.
* `COMMIT` (Подтвердить) — сохранение изменений.
* `ROLLBACK` (Откатить) — отмена всех изменений с момента `BEGIN`.

*Пример (перевод денег):*
~~~sql
BEGIN;
UPDATE accounts SET balance = balance - 1000 WHERE id = 1;
UPDATE accounts SET balance = balance + 1000 WHERE id = 2;
COMMIT;
~~~
Если между двумя `UPDATE` произойдет ошибка, мы выполним `ROLLBACK`, и деньги вернутся на счет.

### 4. Применение в разработке
Транзакции используются везде, где важна целостность:
* Банковские операции.
* Оформление заказов в интернет-магазине (списание товара и создание заказа).
* Системы бронирования (билеты, отели).
