# Практическое задание к Уроку 9

## Цель работы
На практике убедиться, что индекс ускоряет поиск, и научиться анализировать план запроса.

## Что нужно сделать

### Шаг 1. Создание большой таблицы
Выполните скрипт для создания таблицы `big_users` с 1 000 000 записей (генерация займет несколько секунд):

~~~sql
CREATE TABLE big_users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(100)
);

INSERT INTO big_users (name, email)
SELECT 
    'User ' || i,
    'user' || i || '@example.com'
FROM generate_series(1, 1000000) as i;
~~~

### Шаг 2. Поиск без индекса
1. Выполните запрос на поиск пользователя по email:
   ~~~sql
   EXPLAIN ANALYZE SELECT * FROM big_users WHERE email = 'user500000@example.com';
   ~~~
2. Запишите время выполнения (внизу плана будет строка `Execution Time`).
3. Обратите внимание на `Seq Scan` (полный перебор).

### Шаг 3. Создание индекса
1. Создайте индекс на колонку `email`:
   ~~~sql
   CREATE INDEX idx_big_users_email ON big_users (email);
   ~~~
2. Повторите запрос:
   ~~~sql
   EXPLAIN ANALYZE SELECT * FROM big_users WHERE email = 'user500000@example.com';
   ~~~
3. Сравните время выполнения с предыдущим результатом.
4. Убедитесь, что в плане появился `Index Scan`.

### Шаг 4. Анализ
Ответьте на вопросы:
1. Во сколько раз ускорился поиск?
2. Почему индекс не используется, если мы ищем по `name` (у нас нет индекса на этой колонке)?

## Ожидаемый результат
Вы понимаете, что индекс — это мощный инструмент оптимизации. Вы умеете создавать индексы и читать план запроса, чтобы понять, использует ли база данных индекс.
