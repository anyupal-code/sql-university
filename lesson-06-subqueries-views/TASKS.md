# Практическое задание к Уроку 6

## Цель работы
Научиться решать сложные задачи с помощью подзапросов и создавать представления (Views).

## Что нужно сделать

### Шаг 1. Использование подзапросов
1. Напишите запрос, который выведет имена клиентов, которые сделали хотя бы один заказ на сумму больше 10000.
2. Напишите запрос, который выведет название самого дорогого товара (из таблицы `orders`).
3. Напишите запрос, который выведет имя клиента, сделавшего самый дорогой заказ.

### Шаг 2. Создание представлений (Views)
1. Создайте представление `expensive_orders`, которое выводит все заказы с суммой больше 10000.
   ~~~sql
   CREATE VIEW expensive_orders AS 
   SELECT * FROM orders WHERE amount > 10000;
   ~~~
2. Выполните `SELECT * FROM expensive_orders;` — убедитесь, что представление работает.
3. Создайте представление `customer_summary`, которое выводит имя клиента и общую сумму его заказов (используйте `JOIN` и `GROUP BY`).
4. Выполните `SELECT * FROM customer_summary WHERE total > 20000;` — найдите самых активных клиентов.

### Шаг 3. Проверка
Попробуйте изменить данные в базовой таблице (например, добавьте новый заказ). Убедитесь, что представления автоматически обновились при следующем запросе.

---

## Ожидаемый результат
Вы умеете использовать подзапросы для получения промежуточных данных и создавать View, чтобы скрыть сложные запросы за простыми именами.
