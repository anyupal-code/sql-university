---

## Теория

### 1. Требования к проекту
Необходимо спроектировать базу данных для интернет-магазина. Основные сущности:
* **Клиенты** (customers): имя, email, дата регистрации.
* **Товары** (products): название, категория, цена, остаток на складе.
* **Заказы** (orders): дата заказа, клиент, статус (новый, оплачен, доставлен).
* **Позиции заказа** (order_items): какой товар, в каком количестве и по какой цене куплен (связь М:М между заказами и товарами).

### 2. Схема связей
* Один клиент -> много заказов (1:М).
* Один заказ -> много позиций (1:М).
* Один товар -> много позиций (1:М).

### 3. Что нужно сделать
1. Создать все таблицы с правильными типами данных и связями (FOREIGN KEY).
2. Добавить тестовые данные (несколько клиентов, товаров и заказов).
3. Создать индексы для часто используемых колонок (например, `email` у клиентов, `status` у заказов).
4. Написать аналитические запросы (топ продаж, выручка по категориям, активные клиенты).
